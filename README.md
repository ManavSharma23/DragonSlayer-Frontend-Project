# DragonSlayer RPG 🐉

A lightweight, state-driven turn-based RPG web application built with **Vanilla JavaScript**, **HTML5**, and **CSS3**.

## 🎮 Gameplay Features
- **State-Driven Navigation:** Smooth single-page UI updates without external frameworks or page reloads.
- **Turn-Based Combat:** Fight slimes, beasts, ogres, and the final dragon boss with randomized damage, defense mechanics, and XP/gold drops.
- **Item Shop & Inventory:** Purchase weapons, manage equipment statuses, and consume potions to restore health.
- **Responsive Text Display:** Auto-wrapping text container designed for various browser window sizes.

## 🛠️ Built With
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/DragonSlayer-RPG.git
   ```
2. Open `index.html` in any web browser.
